# 引用并评论

选中对话里的任意文本后，原本的「引用文本」按钮会先弹窗索要一条评论，再把**引用的内容与评论作为一个整体**放进输入框。右侧栏预览的文件里的文字，也可以这样引用并评论。

## 行为（对话）

1. 选中文本 → 点击浮出的「引用文本」。
2. 弹窗里，引用内容（灰色、只读）在上，评论直接在同一个块的下半部分输入——输入的文字只出现一次，不会再被回显一遍。
3. 点「保存」后：
   - 有评论：引用原文与评论合并成一个引用块插入输入框；
   - 评论留空：等同原生行为，只插入引用。
4. 点「取消」、按 `Esc`、或点击遮罩，都不插入任何内容。
5. `⌘/Ctrl + Enter` 直接保存。

发送出去的一条消息长这样：

```
> 被引用的原文
>
> 【评论】
> 你写的评论
```

`【评论】` 是刻意保留的独立标记行（英文为 `[Comment]`）。整块是一个引用，若只用空行分隔，读者与模型都只能靠"空行"猜测哪里是引用、哪里是评论；多段引用时空行更无法区分，评论会被当成又一段被引用的原文。标记独占一行后，引用与评论一眼可分，而且仍然是一个完整的引用块。

输入框里它是**一个**引用 chip：标签显示「引用 · N 行」并直接带上评论文字，悬停可查看完整的引用内容与评论——而不是「引用 + 正文」两段。

## 行为（预览文件）

1. 在右侧栏（或浮出的预览面板）里打开文件，选中里面的文字，选区旁同样浮出「引用文本」。
2. 弹窗顶部显示来源 `路径:起-止`；保存后来源会写进引用块的第一行：

```
> 【来源】src/foo.ts:12-18
> 被引用的内容
>
> 【评论】
> 你写的评论
```

英文界面里这两行是 `[Source] src/foo.ts:12-18` 与 `[Comment]`。

3. 行号来自真实源码行，只在**代码**与**纯文本**预览里提供（选中多行时写成一个区间，如 `:12-18`）。
4. Markdown、PDF、Word、PowerPoint 预览只写路径、不写行号：这些是渲染后的版面（PDF 是文本层），没有可对齐的源码行。
5. 引用会插入到**该预览所属会话**的输入框，与在对话里引用的落点一致。

## 说明与限制

- 插件启用期间会接管所有会话的「引用文本」按钮；停用后立即恢复原生行为。
- 引用与评论是一个整体、不可分别编辑：插入后整个块是一个原子 chip，需要修改评论时删除该 chip 重新引用即可。
- 对话里的按钮依赖 DSH 内置的引用交互（`message-quotes` 的 `quote` 交互）；该插件被禁用时，对话里的按钮不会出现（预览里的按钮不依赖它）。
- 输入框处于发送或命令执行状态、或会话不可写时，预览选区旁不显示按钮；若在弹窗打开期间输入框被占用，保存会保留已写的评论并提示重试，不会丢失。
- **不支持的预览**：HTML 预览（渲染在沙盒 iframe 里，页面读不到里面的选区）、表格（xlsx/xls/csv，是单元格选择而不是文本选择）、图片（没有文字）。
- 键盘：`Esc` 取消，`⌘/Ctrl + Enter` 保存，`Tab` 在弹窗内循环；取消后焦点回到打开前的输入位置。
